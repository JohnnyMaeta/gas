## ローカルで確認する
`index.html` をダブルクリックしてブラウザで開くだけ。コピーボタンも動きます。

## GitHub Pagesで公開する手順

リポジトリ名は **`gas`** で確定（2026-07-06 ジョニー決定）。公開URLは **`https://johnnymaeta.github.io/gas/`**。将来の2冊目のページは同リポジトリの `/2/` に置く。

1. GitHub（JohnnyMaeta）で新しいリポジトリ `gas` を作る。公開設定は Public。
2. このフォルダの `index.html` をリポジトリの**ルート**に置いてpush（この `README.md` は任意）。
3. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` に設定して Save。
4. 数分後、`https://johnnymaeta.github.io/gas/` で公開される。
5. 公開されたら実機（スマホ含む）で開いて、コピーボタンの動作まで確認する。
