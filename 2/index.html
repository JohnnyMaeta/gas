『コードを1文字も書かない校務自動化2　学校の裏方編』の読者用ページです。本書の発注文と、実際に動くコードを、まとめてコピーできます。

使い方

  1. 基本は「発注文」をコピーして、自分のチャットAI（ChatGPT / Gemini のWeb版）に貼るのがこの本の流儀です。あなたのAIが返したコードを使ってください。あなたの学校の事情を足した発注文から生まれたコードが、あなたの道具になります。
  2. 急ぐ人は「動くコード」をそのままコピーしても構いません。ここに載っているのは全部、実際に動く形で書いたものです。
  3. 準備は要りません。必要なシート・フォルダ・テンプレートは、最初の1回の実行でコードが自分で作ります。あなたが学校の情報を入れるのは第1章のカレンダーIDだけで、それも練習版から入れば、第1章を最後まで通したあとで構いません。
  4. コードは、仕事のファイルの中に貼ります。スプレッドシートを使う章はスプレッドシートに、ドキュメントを使う章（第3章）はドキュメントに。どちらも入口は拡張機能 → Apps Scriptです。ファイルの中に住まわせておくと、そのファイルを開けば道具もそこにあります。各章の黄色い枠に、貼り付け先を書いてあります。
  5. 1章＝1ファイルです。前の章のコードに継ぎ足さず、章ごとに新しいファイルを作ってください（第2章だけは新しいコードがないので、第1章のファイルをそのまま育てます）。ブラウザのアドレスバーに sheet.new / doc.new と打つと、新しいファイルが1手で開きます（form.new slide.new site.new cal.new meet.new keep.new も同じ）。いちばん最初にログインしたアカウントで作られるので、学校と個人を併用している人は、開いた直後に画面右上のアカウントアイコンを確かめてください。個人のほうで開いていたら、そのファイルは捨てて、学校のアカウントで開いたドライブの「新規」から作り直します。
  6. エラーが出たら、赤い文字を丸ごとコピーしてAIに貼ります。この本で覚えるデバッグ法は、最後までこのひとつだけです。
  7. 初回の▶実行で、承認の画面がなかなか出てこないときは、エディタのページを再読み込み（Ctrl+R / ⌘+R）してから、もう一度▶を押してください。エラーではないので赤い文字も出ず、待っていても何も起きません。保存してあれば、貼ったコードは消えません。それでも出ないときは、ブラウザがポップアップをふさいでいないかを確かめます（詳しくは第1章「承認の儀式」・付録A 12番）。

function main() {
  let calendar = CalendarApp.getCalendarById(CALENDAR_ID);

  // 練習用カレンダーをまだ追加していない場合は、ここで自動的に追加します
  if (!calendar) {
    try {
      calendar = CalendarApp.subscribeToCalendar(CALENDAR_ID);
    } catch (e) {
      throw new Error(
        '練習用カレンダーを追加できませんでした。\n' +
        'コード掲載ページ（付録B）にある「練習用カレンダーを追加」のリンクを押してから、\n' +
        'もう一度▶実行してください。'
      );
    }
  }

  const week = nextWeek_();
  const events = calendar.getEvents(week.start, week.end);

  const rows = events.map(function (event) {
    const startedAt = event.getStartTime();
    return [
      ymd_(startedAt),
      weekdayOf_(startedAt),
      event.isAllDayEvent() ? '終日' : Utilities.formatDate(startedAt, 'Asia/Tokyo', 'H:mm'),
      event.getTitle()
    ];
  });

  const sheet = getOrCreateSheet_();
  if (sheet.getLastRow() > 1) {
    sheet.getRange(2, 1, sheet.getLastRow() - 1, HEADER.length).clearContent();
  }

  if (rows.length === 0) {
    // 静かな成功：仕組みは動いていて、来週の予定がないだけ
    SpreadsheetApp.getActive().toast(
      week.label + ' の予定は0件でした。カレンダーに予定がない週です。',
      '書き出しました', 10
    );
    return;
  }

  sheet.getRange(2, 1, rows.length, HEADER.length).setValues(rows);
  sheet.getRange(2, 1, rows.length, 1).setNumberFormat('@');
  SpreadsheetApp.getActive().toast(week.label + ' の予定を ' + rows.length + ' 件、書き出しました。', '完了', 6);
}

/** 「週予定」シートを、なければ見出しつきで作ります。 */
function getOrCreateSheet_() {
  const ss = SpreadsheetApp.getActive();
  ss.setSpreadsheetTimeZone('Asia/Tokyo'); // 日付がずれないように、先に日本時間にそろえます

  let sheet = ss.getSheetByName(SHEET_NAME);

  if (String(header.getValues()[0][0]) !== HEADER[0]) {

    sheet.setColumnWidth(1, 110);
    sheet.setColumnWidth(2, 50);
    sheet.setColumnWidth(3, 90);
    sheet.setColumnWidth(4, 380);

}

/**
 * 来週の月曜0時から、土曜0時までを返します。
 * スクリプトのタイムゾーン設定に左右されないよう、日本時間で組み立てています。
 */
function nextWeek_() {
  const today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy-MM-dd').split('-').map(Number);
  const anchor = Date.UTC(today[0], today[1] - 1, today[2]);
  const day = new Date(anchor).getUTCDay();           // 0=日 … 6=土
  const untilMonday = ((8 - day) % 7) || 7;           // 次の月曜まであと何日か
  const monday = anchor + untilMonday * 24 * 60 * 60 * 1000;

  const start = new Date(monday - 9 * 60 * 60 * 1000);          // 日本時間の月曜0:00
  const end = new Date(start.getTime() + 5 * 24 * 60 * 60 * 1000); // 日本時間の土曜0:00

  return {
    start: start,
    end: end,
    label: Utilities.formatDate(start, 'Asia/Tokyo', 'M月d日') + 'の週'
  };
}

/** 2026-08-17 の形の文字列にします。 */
function ymd_(date) {
  return Utilities.formatDate(date, 'Asia/Tokyo', 'yyyy-MM-dd');
}

/** 日本時間での曜日を1文字で返します。 */
function weekdayOf_(date) {
  const n = ymd_(date).split('-').map(Number);
  const anchor = new Date(Date.UTC(n[0], n[1] - 1, n[2]));
  return ['日', '月', '火', '水', '木', '金', '土'][anchor.getUTCDay()];
}

function setUpWeeklyTrigger() {
  ScriptApp.getProjectTriggers()
    .filter(function (t) { return t.getHandlerFunction() === 'main'; })
    .forEach(function (t) { ScriptApp.deleteTrigger(t); });

  ScriptApp.newTrigger('main')
    .timeBased()
    .onWeekDay(ScriptApp.WeekDay.FRIDAY)
    .atHour(16)
    .create();
  console.log('毎週金曜16時台に、来週分を自動で書き出すようにしました。');
}

第3章 毎朝の定型文書を、自動でつくらせる

毎朝、様式（テンプレート）から「今日の分」の文書ができあがります。この章だけ、スクリプトはGoogleドキュメントの中に住みます。

この章はドキュメントに貼ります。空のGoogleドキュメントを1枚作って、その 拡張機能 → Apps Script へ。スクリプトが住んでいるドキュメント自身が様式になるので、テンプレートのIDを指定する必要がありません。貼ったらドキュメントを開き直して、メニュー「📄 日次文書」→「様式の見本を入れる」→「今日の分をつくる」の順に押してください。
貼り付け先：Googleドキュメント（様式そのもの）（アドレスバーに doc.new）→ 拡張機能 → Apps Script
発注文（前置きに続けて）
作りたいもの：毎朝、今日の分の文書を自動でつくるGASです。
・Googleドキュメントにコンテナバインドして使います。このスクリプトが入っているドキュメント自身を、様式（テンプレート）として複製してください。テンプレートのIDは指定しません
・保存先のフォルダは、テンプレートと同じ場所に、なければ自動で作ってください
・メニューから「様式の見本を入れる」を実行すると、見出しと《日付》《曜日》が入った学校日誌の見本が、このドキュメントに入るようにしてください。あとから私が自分の様式に書き換えます
・「今日の分をつくる」を実行すると、テンプレートを複製して、《日付》を「2026年8月12日」の形に、《曜日》を「水」に差し替えます
・ファイル名は「2026-08-12_学校日誌」の形にしてください
・同じ日の文書がすでにあるときは、作り直さずに「今日の分はすでにあります」と教えてください
・土日と祝日は作らないようにしてください。祝日はGoogleの日本の祝日カレンダーで判定してください
・日付の処理は、スクリプトのタイムゾーン設定に左右されないように、日本時間で計算してください
・操作は全部、ドキュメント上部の日本語のメニューから選べるようにしてください
・このスクリプトはテンプレートに住んでいるので、複製した文書にもついていきます。ファイル名が日付で始まる文書では、メニューを出さないようにしてください

/**
 * 日次文書くん —— GAS本2 第2章
 *
 * 毎朝、この様式（テンプレート）から「今日の分」の文書を自動でつくります。
 * 学校日誌、週指導計画、打ち合わせ記録。日付と曜日だけが変わる文書のための道具です。
 *
 * 【置き場所】Googleドキュメントを1枚つくって、その 拡張機能 → Apps Script に貼ります。
 * このスクリプトは、そのドキュメントの中に住みます。
 * だから「どのドキュメントを複製するのか」をIDで教える必要がありません。
 * 自分が住んでいるドキュメント、それがテンプレートです。
 *
 * 【最初にやること】貼って保存したら、ドキュメントを開き直して
 * メニュー「📄 日次文書」→「様式の見本を入れる」→「今日の分をつくる」の順に押すだけです。
 */

// ▼ ここだけ、必要なら書き換えてください ------------------------------------
const DOC_NAME = '学校日誌';     // ▼ 文書の名前（できあがるファイル名に使われます）
const FOLDER_NAME = '学校日誌';  // ▼ このテンプレートの隣に作る、保存フォルダの名前
const SKIP_HOLIDAYS = true;      // ▼ true なら土日祝は作りません
// -------------------------------------------------------------------------

const HOLIDAY_CALENDAR_ID = 'ja.japanese#holiday@group.v.calendar.google.com';

/**
 * ドキュメントを開いたときに、メニューを出します。
 *
 * ひとつだけ仕掛けがあります。
 * このスクリプトはテンプレートの中に住んでいるので、テンプレートを複製すると
 * できあがった「今日の分」の文書にも、スクリプトがついていきます。
 * そこでメニューが出ると、日誌から日誌を複製できてしまって混乱するので、
 * ファイル名が日付で始まる文書（＝複製された今日の分）では、メニューを出しません。
 */
function onOpen() {
  if (isGeneratedCopy_(DocumentApp.getActiveDocument().getName())) return;

  DocumentApp.getUi()
    .createMenu('📄 日次文書')
    .addItem('今日の分をつくる', 'createTodayDoc')
    .addSeparator()
    .addItem('様式の見本を入れる', 'insertSampleFormat')
    .addItem('毎朝つくるようにする', 'setUpMorningTrigger')
    .addItem('毎朝つくるのをやめる', 'removeAllTriggers')
    .addToUi();
}

/**
 * 今日の分の文書をつくります。毎朝の自動実行から呼ばれるのも、この関数です。
 */
function createTodayDoc() {
  const template = DocumentApp.getActiveDocument();
  const templateId = template.getId();
  template.saveAndClose(); // 直前の書き換えを確実に反映してから複製します

  const today = new Date();
  const parts = tokyoParts_(today);

  if (SKIP_HOLIDAYS && isSchoolClosed_(parts)) {
    tell_(ymd_(today) + ' はお休みの日なので、文書は作りませんでした。');
    return;
  }

  const templateFile = DriveApp.getFileById(templateId);
  const folder = getOrCreateFolder_(templateFile);
  const fileName = ymd_(today) + '_' + DOC_NAME;

  // 番人：同じ日の文書を二重に作らない
  const existing = folder.getFilesByName(fileName);
  if (existing.hasNext()) {
    tell_('今日の分はすでにあります。\n' + existing.next().getUrl());
    return;
  }

  const copy = templateFile.makeCopy(fileName, folder);
  fillInDate_(copy.getId(), parts);

  tell_('できました。\n' + copy.getUrl());
}

/** ファイル名が日付で始まっていたら、それは複製された「今日の分」です。 */
function isGeneratedCopy_(name) {
  return /^\d{4}-\d{2}-\d{2}_/.test(name);
}

/** テンプレートと同じ場所に、保存フォルダを作ります。 */
function getOrCreateFolder_(templateFile) {
  const parents = templateFile.getParents();
  const parent = parents.hasNext() ? parents.next() : DriveApp.getRootFolder();

  const found = parent.getFoldersByName(FOLDER_NAME);
  if (found.hasNext()) return found.next();
  return parent.createFolder(FOLDER_NAME);
}

/** 複製した文書の《日付》《曜日》を、今日のものに差し替えます。 */
function fillInDate_(fileId, parts) {
  const doc = DocumentApp.openById(fileId);
  const body = doc.getBody();
  body.replaceText('《日付》', parts.year + '年' + parts.month + '月' + parts.day + '日');
  body.replaceText('《曜日》', parts.weekday);
  doc.saveAndClose();
}

/** 土日か、日本の祝日か。 */
function isSchoolClosed_(parts) {
  if (parts.weekday === '土' || parts.weekday === '日') return true;

  const calendar = CalendarApp.getCalendarById(HOLIDAY_CALENDAR_ID);
  if (!calendar) {
    // 番人：祝日カレンダーが読めないときは、黙って止まらずに土日だけで判定する
    console.log('※ 祝日カレンダーが読めなかったので、土日の判定だけで進めました。');
    return false;
  }
  // 日本時間の 0:00 から 23:59 まで。翌日の祝日を拾ってしまわないように幅を切っています
  const start = new Date(Date.UTC(parts.year, parts.month - 1, parts.day) - 9 * 60 * 60 * 1000);
  const end = new Date(start.getTime() + 24 * 60 * 60 * 1000 - 1000);
  return calendar.getEvents(start, end).length > 0;
}

/**
 * 手で押したときは画面に、毎朝の自動実行のときはログに知らせます。
 * 自動実行にはメニューも画面もないので、そのまま alert を呼ぶとエラーになります。
 */
function tell_(message) {
  console.log(message);
  try {
    DocumentApp.getUi().alert(message);
  } catch (e) {
    // 自動実行から呼ばれたときは、画面がないので何もしません
  }
}

/**
 * 日本時間での年・月・日・曜日を取り出します。
 * スクリプトのタイムゾーン設定に左右されないようにしています。
 */
function tokyoParts_(date) {
  const text = Utilities.formatDate(date, 'Asia/Tokyo', 'yyyy-MM-dd');
  const n = text.split('-').map(Number);
  const anchor = new Date(Date.UTC(n[0], n[1] - 1, n[2]));
  return {
    year: n[0],
    month: n[1],
    day: n[2],
    weekday: ['日', '月', '火', '水', '木', '金', '土'][anchor.getUTCDay()]
  };
}

/** 2026-08-12 の形の文字列にします。 */
function ymd_(date) {
  return Utilities.formatDate(date, 'Asia/Tokyo', 'yyyy-MM-dd');
}

function removeTriggers_() {
  const triggers = ScriptApp.getProjectTriggers();
  triggers.forEach(function (t) { ScriptApp.deleteTrigger(t); });
  return triggers.length;
}

/**
 * 反省フォームくん —— GAS本2 第3章
 *
 * 行事名を1行書くだけで、反省アンケートのフォームができます。
 * 回答が集まったら、メニューからまとめまで作れます。
 *
 * 【準備は要りません】
 * メニューの「① テンプレートを用意する」を1回押すと、
 * 5段階3問＋自由記述2問の定番フォームが自動でできます。中身はあとから自由に直せます。
 *
 * 【置き場所】新しいスプレッドシート → 拡張機能 → Apps Script に貼ります。
 */

// ▼ ここだけ、必要なら書き換えてください ------------------------------------
const LIST_SHEET = '行事一覧';   // ▼ 行事を書いていくシートの名前
const SUM_SHEET = 'まとめ';      // ▼ 集計結果を書き出すシートの名前
// -------------------------------------------------------------------------

const LIST_HEADER = ['行事名', '実施日', '回答用URL', '編集用URL', '作成日'];
const TEMPLATE_KEY = 'TEMPLATE_FORM_ID';

    .addItem('シートを作り直す', 'rebuildSheets')

/**
 * ② 行事一覧を上から見て、まだフォームがない行事のフォームを作ります。
 */
function makeForms() {
  const sheet = ensureListSheet_();
  const ui = SpreadsheetApp.getUi();
  const lastRow = sheet.getLastRow();

  if (lastRow < 2) {
    ui.alert('行事一覧に、行事名と実施日を1行書いてから実行してください。');
    return;
  }

  const template = getOrCreateTemplateForm_();
  const templateFile = DriveApp.getFileById(template.getId());
  const values = sheet.getRange(2, 1, lastRow - 1, LIST_HEADER.length).getValues();
  let made = 0;

  for (let i = 0; i < values.length; i++) {
    const name = String(values[i][0]).trim();
    const heldOn = values[i][1];
    const already = String(values[i][2]).trim();

    if (!name) continue;
    if (already) continue; // 番人：作りすぎない

    const copy = templateFile.makeCopy(name + '_反省アンケート');
    const form = FormApp.openById(copy.getId());

    form.setTitle(template.getTitle().replace('《行事名》', name));
    form.setDescription(
      (heldOn ? ymd_(heldOn) + 'に実施した' : '') + name + 'の反省です。お気づきの点をお願いします。'
    );
    publishForm_(form); // 回答用URLを、そのまま配れる状態にする

    sheet.getRange(i + 2, 3).setValue(form.getPublishedUrl());
    sheet.getRange(i + 2, 4).setValue(form.getEditUrl());
    sheet.getRange(i + 2, 5).setValue(ymd_(new Date()));
    made++;
  }

  ui.alert(made > 0
    ? 'フォームを ' + made + ' 本つくりました。回答用URLを職員に送ってください。\n\n' +
      '※「開けません」と言われたら、編集用URLを開いて右上の「公開」を押してから配ってください。'
    : '新しく作る行事はありませんでした。行事名を書いた行に、まだURLが入っていないか確かめてください。');
}

/**
 * ③ いま選んでいる行の行事について、回答をまとめます。
 */
function summarizeSelected() {
  const ss = SpreadsheetApp.getActive();
  const ui = SpreadsheetApp.getUi();
  const sheet = ensureListSheet_();

  if (ss.getActiveSheet().getName() !== LIST_SHEET) {
    ui.alert('「' + LIST_SHEET + '」シートで、まとめたい行事の行をクリックしてから実行してください。');
    return;
  }

  const row = ss.getActiveRange().getRow();
  if (row < 2) {
    ui.alert('見出しの行が選ばれています。行事の行をクリックしてから実行してください。');
    return;
  }

  const name = String(sheet.getRange(row, 1).getValue()).trim();
  const editUrl = String(sheet.getRange(row, 4).getValue()).trim();
  if (!editUrl) {
    ui.alert('この行にはまだフォームがありません。先に「② 行事一覧からフォームを作る」を実行してください。');
    return;
  }

  const form = FormApp.openByUrl(editUrl);
  const responses = form.getResponses();
  if (responses.length === 0) {
    ui.alert('「' + name + '」には、まだ回答がありません。');
    return;
  }

  writeSummary_(name, responses);
  ss.getSheetByName(SUM_SHEET).activate();
}

/** 壊れたシートを作り直します。書いてある行事は消えません。 */
function rebuildSheets() {
  ensureListSheet_();
  SpreadsheetApp.getUi().alert('シートを整えました。');
}

/** 行事一覧シートを、なければ見出しつきで作ります。 */
function ensureListSheet_() {
  const ss = SpreadsheetApp.getActive();
  let sheet = ss.getSheetByName(LIST_SHEET);

  if (!sheet) {
    sheet = ss.insertSheet(LIST_SHEET, 0);
  }
  const header = sheet.getRange(1, 1, 1, LIST_HEADER.length);
  if (String(header.getValues()[0][0]) !== LIST_HEADER[0]) {
    header.setValues([LIST_HEADER]).setFontWeight('bold').setBackground('#e8eaed');
    sheet.setFrozenRows(1);
    sheet.setColumnWidth(1, 220);
    sheet.setColumnWidth(3, 320);
    sheet.setColumnWidth(4, 320);
  }
  return sheet;
}

/** テンプレートのフォームを探して、なければ定番の質問で作ります。 */
function getOrCreateTemplateForm_() {
  const props = PropertiesService.getScriptProperties();
  const saved = props.getProperty(TEMPLATE_KEY);

  if (saved) {
    try {
      return FormApp.openById(saved);
    } catch (e) {
      // テンプレートが捨てられていたら、作り直す
      props.deleteProperty(TEMPLATE_KEY);
    }
  }

  const form = FormApp.create('《行事名》 反省アンケート');
  form.setDescription('行事の運営についての反省です。');
  form.setCollectEmail(false);

  const scales = [
    '準備は計画どおりに進みましたか',
    '当日の運営は落ち着いて進みましたか',
    '子どもたちの活動として充実していましたか'
  ];
  scales.forEach(function (title) {
    form.addScaleItem()
      .setTitle(title)
      .setBounds(1, 5)
      .setLabels('そう思わない', 'そう思う')
      .setRequired(true);
  });

  form.addParagraphTextItem().setTitle('よかった点があれば書いてください');
  form.addParagraphTextItem().setTitle('来年度に向けて変えたい点があれば書いてください');

  props.setProperty(TEMPLATE_KEY, form.getId());
  return form;
}

/**
 * フォームを「公開」にします。
 * いまのフォームは、公開していないと回答用URLを開いてもらえません。
 * 公開の考え方がない古い形式のフォームのときは、回答の受付をオンにします。
 */
function publishForm_(form) {
  try {
    if (form.supportsAdvancedResponderPermissions()) {
      form.setPublished(true);
    } else {
      form.setAcceptingResponses(true);
    }
  } catch (e) {
    // 公開できなくても、フォーム作りは止めません。
    // 編集用URLを開いて、右上の「公開」を押してから配ってください。
  }
}

/** 回答を、まとめシートに書き出します。 */
function writeSummary_(eventName, responses) {
  const ss = SpreadsheetApp.getActive();
  let sheet = ss.getSheetByName(SUM_SHEET);
  if (!sheet) sheet = ss.insertSheet(SUM_SHEET);
  sheet.clear();

  const rows = [];
  rows.push([eventName + '　反省まとめ', '', '', '', '', '', '']);
  rows.push(['回答数', responses.length + ' 件', '', '', '', '', '']);
  rows.push(['作成日', ymd_(new Date()), '', '', '', '', '']);
  rows.push(['', '', '', '', '', '', '']);

  // 質問ごとに回答を集める
  const scaleAnswers = {};  // 質問 → [数値]
  const textAnswers = {};   // 質問 → [文章]
  const order = [];

  responses.forEach(function (response) {
    response.getItemResponses().forEach(function (item) {
      const title = item.getItem().getTitle();
      const type = item.getItem().getType();
      if (order.indexOf(title) === -1) order.push(title);

      if (type === FormApp.ItemType.SCALE) {
        if (!scaleAnswers[title]) scaleAnswers[title] = [];
        scaleAnswers[title].push(Number(item.getResponse()));
      } else {
        const text = String(item.getResponse()).trim();
        if (!text) return;
        if (!textAnswers[title]) textAnswers[title] = [];
        textAnswers[title].push(text);
      }
    });
  });

  rows.push(['【5段階の質問】', '平均', '1', '2', '3', '4', '5']);
  order.forEach(function (title) {
    if (!scaleAnswers[title]) return;
    const nums = scaleAnswers[title];
    const sum = nums.reduce(function (a, b) { return a + b; }, 0);
    const avg = Math.round((sum / nums.length) * 10) / 10;
    const count = [0, 0, 0, 0, 0];
    nums.forEach(function (n) { if (n >= 1 && n <= 5) count[n - 1]++; });
    rows.push([title, avg, count[0], count[1], count[2], count[3], count[4]]);
  });

  rows.push(['', '', '', '', '', '', '']);
  order.forEach(function (title) {
    if (!textAnswers[title]) return;
    rows.push(['【' + title + '】', '', '', '', '', '', '']);
    textAnswers[title].forEach(function (text) {
      rows.push(['・' + text, '', '', '', '', '', '']);
    });
    rows.push(['', '', '', '', '', '', '']);
  });

  sheet.getRange(1, 1, rows.length, 7).setValues(rows);
  sheet.getRange(1, 1).setFontSize(14).setFontWeight('bold');
  sheet.setColumnWidth(1, 520);
  sheet.getRange(1, 1, rows.length, 1).setWrap(true);
}

 * すでに書いてある行事や備考は、聞いたうえで残せます。

function buildYear() {
  const ui = SpreadsheetApp.getUi();
  const thisYear = Number(Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy'));
  const thisMonth = Number(Utilities.formatDate(new Date(), 'Asia/Tokyo', 'MM'));

    defaultYear + ' と入れると、' + defaultYear + '年4月1日から' + (defaultYear + 1) + '年3月31日までを作ります。',
    ui.ButtonSet.OK_CANCEL
  );

  const year = Number(String(answer.getResponseText()).trim());
  if (!year || year < 2000 || year > 2100) {
    ui.alert('西暦4桁の数字で入力してください。（入力されたもの: ' + answer.getResponseText() + '）');
    return;
  }

  const ss = SpreadsheetApp.getActive();
  ss.setSpreadsheetTimeZone('Asia/Tokyo'); // 日付がずれないように、先に日本時間にそろえます

  let sheet = ss.getSheetByName(SHEET_NAME);

      '「' + SHEET_NAME + '」にはすでに中身があります',
      '作り直すと、行事や備考も消えます。続けますか。',
      ui.ButtonSet.OK_CANCEL
    );
    if (ok !== ui.Button.OK) return;
    sheet.clear();
    sheet.setConditionalFormatRules([]);
  }
  if (!sheet) sheet = ss.insertSheet(SHEET_NAME, 0);

  const holidays = fetchHolidays_(year);
  const rows = [];
  const holidayRows = [];

  let cursor = Date.UTC(year, 3, 1);          // 4月1日
  const last = Date.UTC(year + 1, 2, 31);     // 翌年3月31日

  while (cursor <= last) {
    const d = new Date(cursor);
    const key = Utilities.formatDate(d, 'UTC', 'yyyy-MM-dd');
    const weekday = ['日', '月', '火', '水', '木', '金', '土'][d.getUTCDay()];
    const holidayName = holidays[key] || '';
    const closed = (weekday === '土' || weekday === '日' || holidayName !== '');

    rows.push([
      new Date(cursor + 3 * 60 * 60 * 1000), // 日本時間の正午。どのタイムゾーンでも日付がずれません
      weekday,
      closed ? '／' : '◯',
      closed ? '／' : '◯',
      holidayName,
      ''
    ]);
    if (holidayName) holidayRows.push(rows.length + 1); // 見出しの分で +1

    cursor += 24 * 60 * 60 * 1000;
  }

  sheet.getRange(1, 1, 1, HEADER.length).setValues([HEADER])
    .setFontWeight('bold').setBackground('#e8eaed').setHorizontalAlignment('center');
  sheet.getRange(2, 1, rows.length, HEADER.length).setValues(rows);

  jumpToToday();

}

/**
 * 今日の行までスクロールします。
 * 今日が載っていない年度の表なら、いちばん上に戻るだけです。
 */
function jumpToToday() {
  const sheet = SpreadsheetApp.getActive().getSheetByName(SHEET_NAME);
  if (!sheet) return;

  const lastRow = sheet.getLastRow();
  if (lastRow < 2) return;

  const today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy-MM-dd');
  const dates = sheet.getRange(2, 1, lastRow - 1, 1).getValues();

  for (let i = 0; i < dates.length; i++) {
    const value = dates[i][0];
    if (!(value instanceof Date)) continue;
    if (Utilities.formatDate(value, 'Asia/Tokyo', 'yyyy-MM-dd') === today) {
      sheet.setActiveSelection(sheet.getRange(i + 2, 1, 1, HEADER.length));
      return;
    }
  }
  sheet.setActiveSelection(sheet.getRange(2, 1));
}

/**
 * 出校・給食の◯と／を、日付から判定し直します。
 * 土日祝を休みとして入れ直すので、行事で振替になった日は手で直してください。
 */
function refillSchoolDays() {
  const ui = SpreadsheetApp.getUi();
  const sheet = SpreadsheetApp.getActive().getSheetByName(SHEET_NAME);
  if (!sheet || sheet.getLastRow() < 2) {
    ui.alert('先に「1年分の日付をつくる」を実行してください。');
    return;
  }

  const lastRow = sheet.getLastRow();
  const dates = sheet.getRange(2, 1, lastRow - 1, 1).getValues();
  const first = dates[0][0];
  if (!(first instanceof Date)) {
    ui.alert('日付の列（A列）に日付が入っていません。');
    return;
  }

  const year = Number(Utilities.formatDate(first, 'Asia/Tokyo', 'yyyy'));
  const month = Number(Utilities.formatDate(first, 'Asia/Tokyo', 'MM'));
  const holidays = fetchHolidays_(month >= 4 ? year : year - 1);

  const marks = dates.map(function (row) {
    const value = row[0];
    if (!(value instanceof Date)) return ['', ''];
    const key = Utilities.formatDate(value, 'Asia/Tokyo', 'yyyy-MM-dd');
    const n = key.split('-').map(Number);
    const day = new Date(Date.UTC(n[0], n[1] - 1, n[2])).getUTCDay(); // 0=日 6=土
    const closed = (day === 0 || day === 6 || holidays[key]);
    return closed ? ['／', '／'] : ['◯', '◯'];
  });

  sheet.getRange(2, 3, marks.length, 2).setValues(marks);
  ui.alert('出校・給食を入れ直しました。');
}

/**
 * 色は、コードではなく「条件付き書式」に任せます。
 * こうしておくと、日付を書き足しても色が勝手についてきます。
 */
function applyColorRules_(sheet, rowCount) {
  const range = sheet.getRange(2, 1, rowCount, HEADER.length);
  const rules = [
    SpreadsheetApp.newConditionalFormatRule()
      .whenFormulaSatisfied('=$A2=TODAY()')
      .setBackground(TODAY_COLOR)
      .setRanges([range]).build(),
    SpreadsheetApp.newConditionalFormatRule()
      .whenFormulaSatisfied('=WEEKDAY($A2)=7')
      .setBackground(SATURDAY_COLOR)
      .setRanges([range]).build(),
    SpreadsheetApp.newConditionalFormatRule()
      .whenFormulaSatisfied('=WEEKDAY($A2)=1')
      .setBackground(SUNDAY_COLOR)
      .setRanges([range]).build()
  ];
  sheet.setConditionalFormatRules(rules);
}

/** 日本の祝日を、日付をキーにした一覧にして返します。 */
function fetchHolidays_(year) {
  const map = {};
  const calendar = CalendarApp.getCalendarById(HOLIDAY_CALENDAR_ID);
  if (!calendar) {
    // 番人：祝日カレンダーが読めなくても、黙って止まらない
    SpreadsheetApp.getActive().toast('祝日カレンダーが読めませんでした。土日だけで判定します。', 'お知らせ', 8);
    return map;
  }

  const start = new Date(Date.UTC(year, 3, 1) - 9 * 60 * 60 * 1000);
  const end = new Date(Date.UTC(year + 1, 3, 1) - 9 * 60 * 60 * 1000);
  calendar.getEvents(start, end).forEach(function (event) {
    const key = Utilities.formatDate(event.getStartTime(), 'Asia/Tokyo', 'yyyy-MM-dd');
    map[key] = event.getTitle();
  });
  return map;
}

/**
 * 所要（分）から、終了時刻と、次の項目の開始時刻を計算します。
 * 開始時刻を書くのは、いちばん上の1行だけで大丈夫です。
 */
function recalcTimes() {
  const sheet = ensureSheet_();
  const lastRow = sheet.getLastRow();
  if (lastRow < 2) {
    SpreadsheetApp.getUi().alert('先に「進行表をつくる」を実行するか、1行目に開始時刻を書いてください。');
    return;
  }

  const range = sheet.getRange(2, 1, lastRow - 1, 3);
  const values = range.getValues();
  let cursor = parseTime_(values[0][0]);

  if (cursor === null) {
    SpreadsheetApp.getUi().alert(
      'いちばん上の開始時刻が読めません。「8:30」のように、半角の数字とコロンで書いてください。\n' +
      '（いま入っているもの: ' + values[0][0] + '）'
    );
    return;
  }

  for (let i = 0; i < values.length; i++) {
    const minutes = Number(values[i][1]);
    if (!minutes || minutes <= 0) {
      // 所要が空の行は、進行表の終わりとみなします
      values[i][0] = (i === 0) ? formatTime_(cursor) : '';
      values[i][2] = '';
      continue;
    }
    values[i][0] = formatTime_(cursor);
    values[i][2] = formatTime_(cursor + minutes);
    cursor += minutes;
  }

  range.setNumberFormat('@'); // 時刻は文字として扱います（勝手に日付に化けないように）
  range.setValues(values);
  markNow();
}

  const values = sheet.getRange(2, 1, lastRow - 1, 3).getValues();
  const now = nowMinutes_();

  const marks = [];
  const colors = [];
  let hit = 0;

  for (let i = 0; i < values.length; i++) {
    const start = parseTime_(values[i][0]);
    const end = parseTime_(values[i][2]);

    if (start === null || end === null) {
      marks.push(['']);
      colors.push(['#ffffff']);
      continue;
    }
    if (now >= start && now < end) {
      marks.push(['▶ あと' + (end - now) + '分']);
      colors.push([NOW_COLOR]);
      hit = i + 2;
    } else if (now >= end) {
      marks.push(['済']);
      colors.push([DONE_COLOR]);
    } else {
      marks.push(['']);
      colors.push(['#ffffff']);
    }
  }

  sheet.getRange(2, 6, marks.length, 1).setValues(marks);
  sheet.getRange(2, 1, colors.length, HEADER.length).setBackgrounds(
    colors.map(function (c) { return new Array(HEADER.length).fill(c[0]); })
  );

  // 自動実行から呼ばれたときに選択でつまずかないよう、ここだけ保険をかけています
  if (hit > 0) {
    try {
      sheet.setActiveSelection(sheet.getRange(hit, 1, 1, HEADER.length));
    } catch (e) {
      // 画面を開いていないときは、選択できなくても構いません
    }
  }
  return hit;
}

/** 「8:30」を、0時からの分数に直します。読めないときは null。 */
function parseTime_(text) {
  // 手で打った「8:30」をスプレッドシートが時刻データに変えてしまうことがあるので、
  // その場合は見た目どおりの時刻に読み直します
  if (text instanceof Date) {
    text = Utilities.formatDate(text, SpreadsheetApp.getActive().getSpreadsheetTimeZone(), 'H:mm');
  }
  const s = String(text).trim().replace('：', ':');
  const m = s.match(/^(\d{1,2}):(\d{1,2})$/);
  if (!m) return null;
  const hour = Number(m[1]);
  const minute = Number(m[2]);
  if (hour > 23 || minute > 59) return null;
  return hour * 60 + minute;
}

/** 分数を「8:30」の形に戻します。 */
function formatTime_(minutes) {
  const wrapped = ((minutes % 1440) + 1440) % 1440;
  const hour = Math.floor(wrapped / 60);
  const minute = wrapped % 60;
  return hour + ':' + (minute < 10 ? '0' + minute : minute);
}

/** いまの時刻を、日本時間で「0時からの分数」にします。 */
function nowMinutes_() {
  const text = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'HH:mm');
  return parseTime_(text);
}

function postToChat_(message) {

      payload: JSON.stringify({ text: message }),
      muteHttpExceptions: true
    });

  }
}
