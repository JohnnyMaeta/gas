コードを1文字も書かない校務自動化｜コード＆発注文一覧

『コードを1文字も書かない校務自動化——AIに書かせる、先生のためのGASレシピ』の読者用ページです。本書の発注文と、AIが返してくる想定のコードを、まとめてコピーできます。

『校務自動化3（Webアプリ編）』から来た人へ：3冊目の第6章「教室に、ボタンを置く」は新しく作らせるので、ここのコードを貼る必要はありません。元ネタを見たい人は 第7章 教室に置く「そうだんボタン」 へ。見たら 3冊目のページ に戻ってください。

使い方

  1. 基本は「発注文」をコピーして、自分のチャットAI（ChatGPT / Gemini のWeb版）に貼るのがこの本の流儀です。あなたのAIが返したコードを使ってください。
  2. 急ぐ人は「想定コード」をそのままコピーしても動きます（差し替えが要る箇所は黄色の注意書きに書いてあります）。
  3. 貼り付け先はスプレッドシート「GAS練習」の「拡張機能 → Apps Script」。第3章からは1章＝1ファイル（ファイル欄の「＋」→「スクリプト」）で、前の章のコードは消さないでください。
  4. エラーが出たら、赤い文字を丸ごとコピーしてAIに貼ります。

いつもの前置き（発注テンプレ）

どの発注も、この前置きから始めます。第2章以降の発注文の頭に付けてください。

発注テンプレ（全レシピ共通）
私はプログラミング未経験の教員です。Google Apps Scriptのコードを書いてください。
条件：(1) コードは1つにまとめる (2) 私が書き換える場所には日本語のコメントで「▼」を付ける (3) シート名の間違いなど、ありがちなミスは日本語のエラーメッセージで教えてくれる仕組みを入れる。
まず、何をするコードか1行で説明してから、コードを見せてください。

第1章 最初の1本

A1に今日の日付、B1に「GAS、動きました」と入れるだけの動作確認。GASが動くことを体で確かめる1本です。

発注文
Googleスプレッドシートで使うGASを書いてください。いま開いているシートのA1セルに今日の日付、B1セルに「GAS、動きました」と入力するだけの、いちばん簡単なものをお願いします。
想定コード（コード.gs）
function myFirstScript() {
  const sheet = SpreadsheetApp.getActiveSheet();
  sheet.getRange("A1").setValue(new Date());
  sheet.getRange("B1").setValue("GAS、動きました");
}

第2章 毎朝、自分にメールが届く

既定カレンダーの今日の予定を、毎朝自分のGmailに届けます。トリガーは「時間主導型・日付ベース・午前6〜7時」。書き換える場所はゼロです。

先にプロジェクトの設定（歯車マーク）でタイムゾーンが「(GMT+09:00) 日本標準時」になっているか確認してください。第1章の練習コードは消して、これを貼って構いません。
発注文（前置きに続けて）
自分のGoogleカレンダー（既定カレンダー）から今日の予定をすべて取り出して、自分のGmailアドレスに件名「【今日の予定】」でメールを送ってください。予定は「・時刻 タイトル」の箇条書きで、終日予定は「終日」と表記してください。予定が1件もない日は「今日の予定はありません。」という本文で送ってください。カレンダーのIDやメールアドレスを私が入力しなくても動くようにしてください。
想定コード（コード.gs）
function sendTodaySchedule() {
  const calendar = CalendarApp.getDefaultCalendar();
  const start = new Date();
  start.setHours(0, 0, 0, 0);
  const end = new Date(start.getTime() + 24 * 60 * 60 * 1000);
  const events = calendar.getEvents(start, end);

  let body;
  if (events.length === 0) {
    body = '今日の予定はありません。';
  } else {
    const lines = events.map(e => {
      const time = e.isAllDayEvent()
        ? '終日'
        : Utilities.formatDate(e.getStartTime(), Session.getScriptTimeZone(), 'HH:mm');
      return '・' + time + ' ' + e.getTitle();
    });
    body = '今日の予定です。\n\n' + lines.join('\n');
  }

  MailApp.sendEmail(Session.getActiveUser().getEmail(), '【今日の予定】', body);
}

発展：学校の共有カレンダー版に改造する

既定カレンダーではなく、共有されている学校の行事カレンダーを読む版です。

▼の行の 'ここにカレンダーIDを貼る' を、自分で調べたカレンダーIDに差し替えてください（調べ方は本書第2章）。カレンダーIDをチャットAIに貼らないのが本書の線引きです。この関数は基本版と同名なので、置き換えて使います。
改造の発注文（さっきの会話の続きで）
このコードを改造してください。既定カレンダーではなく、指定したカレンダーIDのカレンダーから今日の予定を取ってください。カレンダーIDはあとで私が自分で貼り替えるので、コードの先頭に「▼」のコメント付きの定数にしてください。IDが間違っているなどでカレンダーが見つからないときは、エラーで止まるのではなく、「カレンダーが見つかりません。IDと共有設定を確認してください」という内容のメールを自分宛に送ってください。
想定コード（コード.gs・基本版と差し替え）
// ▼ ここに学校カレンダーのIDを貼り付けてください
const CALENDAR_ID = 'ここにカレンダーIDを貼る';

function sendTodaySchedule() {

第3章 締切を見張らせる

「締切一覧」シートを毎朝見回り、3日前と当日の締切だけを1通のメールに。シートがなければ、初回実行時にGASが見出し付きで自作します。トリガーは「時間主導型・日付ベース・午前6〜7時」。

ファイル欄の「＋」→「スクリプト」で 第3章 ファイルを作って貼ってください（前の章のコードは消さない）。「締切一覧」のタブ名は人間が変えないこと。
発注文（前置きに続けて）
Googleスプレッドシートで使うGASを書いてください。「締切一覧」という名前のシートを使います。
もしそのシートがなければ、1行目に「締切の名前」「締切日」「メモ」「リンク」の見出しを入れて自動で作成し、「シートを作りました。締切を書き込んでください」と自分のGmailにメールを送って、そこで終わってください。
シートがあるときは、締切日が3日前と当日にあたる行をすべて拾い、締切の名前とリンクを1通のメールにまとめて、自分宛に送ってください。
通知するタイミングは配列の定数にして、あとから「7日前」も足せるようにしてください。
締切日は文字としてではなく日付として扱い、今日との日数の差で判定してください。
該当する行が1つもない日は、メールを送らないでください。
シートの作成もメールアドレスの指定も、私が手作業でしなくて済むようにしてください。
想定コード（第3章.gs）
const NOTIFY_DAYS_BEFORE = [3, 0];
const SHEET_NAME = '締切一覧';

function watchDeadlines() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const myEmail = Session.getActiveUser().getEmail();
  let sheet = ss.getSheetByName(SHEET_NAME);

  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
    sheet.getRange(1, 1, 1, 4)
      .setValues([['締切の名前', '締切日', 'メモ', 'リンク']]);
    MailApp.sendEmail(myEmail, '【締切見張り】シートを作りました',
      '「締切一覧」シートを作りました。締切を書き込んでください。');
    return;
  }

  const rows = sheet.getDataRange().getValues();
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  const ONE_DAY_MS = 24 * 60 * 60 * 1000;
  const lines = [];

  rows.slice(1).forEach(row => {
    const name = row[0];      // A列: 締切の名前
    const deadline = row[1];  // B列: 締切日
    const url = row[3];       // D列: リンク（C列のメモは読まない）
    if (!(deadline instanceof Date)) return;

    const d = new Date(deadline);
    d.setHours(0, 0, 0, 0);
    const daysLeft = Math.round((d - today) / ONE_DAY_MS);
    if (!NOTIFY_DAYS_BEFORE.includes(daysLeft)) return;

    const label = daysLeft === 0 ? '【本日締切】' : `【残り${daysLeft}日】`;
    lines.push(label + name + (url ? '\n' + url : ''));
  });

  if (lines.length === 0) return;
  MailApp.sendEmail(myEmail, `【締切見張り】${lines.length}件`, lines.join('\n\n'));
}

第4章 フォームが送られた瞬間に動く

振り返りフォームで「先生と話したい」に「ある」が付いた瞬間、自分にメールが届きます。トリガーは「スプレッドシートから・フォーム送信時」。エディタの「実行」ボタンでは動かせません（フォーム送信でテスト）。

先にフォーム（質問は「出席番号」「今日の授業はどうだった？」「先生と話したいことは？」の3つ）を作り、回答先を「GAS練習」につないでください。フォームの質問文とコード内の質問文は一字一句同じであること。ファイルは 第4章 を新規作成。
発注文（前置きに続けて）
Googleフォームの回答が送信された瞬間に動くGASを書いてください。回答はスプレッドシートに連携済みです。フォームの質問は「出席番号」「今日の授業はどうだった？」「先生と話したいことは？」の3つです。
「先生と話したいことは？」の答えが「ある」だったときだけ、「【振り返り】◯番さんが話したいそうです」という件名のメールを、この仕組みを設置した本人（私）宛に送ってください。答えが「ない」のときは、何もしないでください。
メールアドレスは私が入力しなくても動くようにしてください。
想定コード（第4章.gs）
function onReflectionSubmit(e) {
  const answers = e.namedValues;
  if (!answers['先生と話したいことは？']) {
    throw new Error('質問「先生と話したいことは？」が見つかりません。フォームの質問文とコードが一致しているか確認してください。');
  }
  const number = answers['出席番号'] ? answers['出席番号'][0] : '不明';
  const talk = answers['先生と話したいことは？'][0];

  if (talk !== 'ある') return;

  MailApp.sendEmail(
    Session.getEffectiveUser().getEmail(),
    `【振り返り】${number}番さんが話したいそうです`,
    `今日の振り返りで、出席番号${number}の子が「先生と話したいことがある」を選びました。\n早めに声をかけてあげてください。`
  );
}

第5章 数えて、まとめて、報告する

第4章の振り返りフォームの回答を、毎日夕方に1通のダイジェスト（件数・選択肢の分布・「ある」の出席番号）にして届けます。トリガーは「時間主導型・日付ベース・午後4〜5時」。回答が0件の日は沈黙します。

第4章のフォームと「フォームの回答 1」シートをそのまま使います。ファイルは 第5章 を新規作成。選択肢の文言を変えた人は、コード内の CHOICES も合わせてください。
発注文（前置きに続けて）
第4章から使っているスプレッドシートの「フォームの回答 1」シートを集計するGASを書いてください。質問は「出席番号」「今日の授業はどうだった？」「先生と話したいことは？」の3つです。
今日送信された回答だけを対象に、①回答の件数 ②「今日の授業はどうだった？」の選択肢ごとの件数（0件の選択肢も表示）③「先生と話したいことは？」が「ある」だった出席番号 を、1通のメールにまとめて自分宛に送ってください。回答の件数は、件名に入れてください。
今日の回答が1件もない日は、何も送らないでください。
シートが見つからないときは、日本語のエラーメッセージで教えてください。
メールアドレスは私が入力しなくても動くようにしてください。
想定コード（第5章.gs）
const CHOICES = ['4 よくわかった', '3 だいたいわかった',
                 '2 少しむずかしかった', '1 むずかしかった'];

function sendReflectionDigest() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName('フォームの回答 1');
  if (!sheet) throw new Error('「フォームの回答 1」シートが見つかりません。タブ名を確認してください。');

  const rows = sheet.getDataRange().getValues();
  const header = rows[0];
  const colNumber = header.indexOf('出席番号');
  const colScore = header.indexOf('今日の授業はどうだった？');
  const colTalk = header.indexOf('先生と話したいことは？');
  if (colNumber === -1 || colScore === -1 || colTalk === -1) {
    throw new Error('見出し（質問文）が見つかりません。フォームの質問文を変えていないか確認してください。');
  }

  const today = new Date();
  today.setHours(0, 0, 0, 0);
  const ONE_DAY_MS = 24 * 60 * 60 * 1000;

  const counts = {};
  const talkNumbers = [];
  let total = 0;

  rows.slice(1).forEach(row => {
    const stamp = row[0];
    if (!(stamp instanceof Date)) return;
    const d = new Date(stamp);
    d.setHours(0, 0, 0, 0);
    if (Math.round((d - today) / ONE_DAY_MS) !== 0) return;

    total++;
    counts[row[colScore]] = (counts[row[colScore]] || 0) + 1;
    if (row[colTalk] === 'ある') talkNumbers.push(row[colNumber]);
  });

  if (total === 0) return;

  const lines = CHOICES.map(c => `・${c}：${counts[c] || 0}件`);
  let body = '今日の授業はどうだった？\n' + lines.join('\n');
  if (talkNumbers.length > 0) {
    body += `\n\n先生と話したい：${talkNumbers.join('番、')}番`;
  }
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    `【振り返りダイジェスト】${total}件`, body);
}

第6章 フォームを作る作業もAIに

実行するたびに、ルーブリックからフォームを1本自動生成します。貼り付け先はいつものシートではなく、アドレスバーに script.new と打って開いた新品のプロジェクト（承認は出直しになります）。

タイトルと観点は自分の単元に差し替えて発注してください。できたフォームはマイドライブ直下にあります。集計までさせたいフォームは、「回答」タブから緑のスプレッドシートアイコンで連携する一手間を忘れずに。
発注文（前置きに続けて・観点は差し替え）
Googleフォームを自動で作るGASを書いてください。実行すると、次の内容のフォームが新しく作られるようにしてください。
・フォームのタイトル：「ごんぎつね ふりかえり」
・質問1：「出席番号」（記述式・必須）
・次のルーブリックの各観点を、それぞれラジオボタンの質問にしてください（必須）。選択肢はすべて「4 十分できた」「3 だいたいできた」「2 少しむずかしかった」「1 むずかしかった」の4つです。
　・登場人物の気持ちを想像しながら読めた
　・友だちの考えと自分の考えをくらべられた
・最後の質問：「先生と話したいことは？」（ラジオボタン、選択肢は「ない」「ある」）
実行したら、フォームの編集用URLと回答用URLの両方を、実行ログに表示してください。
想定コード（script.new の新規プロジェクト）
function createReflectionForm() {
  const form = FormApp.create('ごんぎつね ふりかえり');

  form.addTextItem().setTitle('出席番号').setRequired(true);

  const rubric = [
    '登場人物の気持ちを想像しながら読めた',
    '友だちの考えと自分の考えをくらべられた'
  ];
  const choices = ['4 十分できた', '3 だいたいできた',
                   '2 少しむずかしかった', '1 むずかしかった'];

  rubric.forEach(title => {
    form.addMultipleChoiceItem().setTitle(title)
      .setChoiceValues(choices).setRequired(true);
  });

  form.addMultipleChoiceItem().setTitle('先生と話したいことは？')
    .setChoiceValues(['ない', 'ある']).setRequired(true);

  Logger.log('編集用URL: ' + form.getEditUrl());
  Logger.log('回答用URL: ' + form.getPublishedUrl());
}

第7章 教室に置く「そうだんボタン」

子どもが押すと「◯◯さんが先生に相談があるそうです」と担任にメールが届くWebアプリ。GASとHTMLの2ファイルで1セットです。デプロイは「次のユーザーとして実行：自分」「アクセスできるユーザー：組織内の全員」。

HTMLファイルはファイル欄の「＋」→「HTML」で index という名前で作成（GAS側が 'index' という名前でページを探すため）。教室で公開する前に管理職・情報担当へ一言。コードを直したら「デプロイを管理 → 新バージョン」を忘れずに。
発注文（前置きに続けて）
GASでWebアプリを作ってください。
開くと、画面の真ん中に「先生に相談がある」というボタンが1つだけある、シンプルなページを表示してください。子どもがタブレットで使うので、ボタンは大きくしてください。
ボタンが押されたら、押した人のアカウント（メールアドレス）を自動で調べて、「【そうだんボタン】◯◯さんが先生に相談があるそうです」という件名のメールを、この仕組みを設置した私宛に送ってください。アカウントが調べられない場合は「どなたか」としてください。
送信できたら、押した子の画面に「先生に伝わりました」と表示し、送信したあとはボタンを押せないようにしてください。
相談の内容を入力する欄は、作らないでください。
想定コード 1/2（第7章.gs）
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('そうだんボタン');
}

function notifyTeacher() {
  const visitor = Session.getActiveUser().getEmail();
  const who = visitor ? visitor + ' さん' : 'どなたか';
  MailApp.sendEmail(
    Session.getEffectiveUser().getEmail(),
    `【そうだんボタン】${who}が先生に相談があるそうです`,
    `${who}が先生に相談があるそうです。声をかけてあげてください。`
  );
}
